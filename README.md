# Take A Break

Take A Break is a workplace productivity and break timer plugin for WordPress designed to keep users on track while offering a personalized experience.

## Core Features

- Up to 3 simultaneous timers (lunch, break, and project focus)
- Customizable backgrounds, themes, and timer colors
- Alarm audio support via YouTube links or Spotify links
- Floating Picture-in-Picture (PiP) mode so timers stay visible while users work in other tabs
- Firebase cloud presets so timer configurations persist across sessions
