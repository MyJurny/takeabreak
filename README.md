# takeabreak
Take A Break: A workplace productivity and break timer plugin for WordPress designed to keep users on track while offering a personalized experience with youtube links, Spotify Playlist etc.  Support for up to 3 simultaneous timers (lunch, break, project focus). 

Current Built Features:

Up to 3 simultaneous, independent timers (Lunch, Quick Break, Deep Work).

Floating Picture-in-Picture (PiP) mode to keep the timer visible over other windows.

Customizable background visuals, themes, and UI colors.

Firebase Integration: Cloud preset manager to save user timer configs.

Audio Link Integration: Play custom alarms from YouTube or Spotify links.
